# Presentio Transcript

## Scarica l’app

Disponibile per **Windows, Mac Apple Silicon e Mac Intel**.

**[Apri sempre l’ultima release disponibile](https://github.com/endriu2795/presentio-transcript-releases/releases/latest)**

Gli installer sono allegati alle **[Releases](https://github.com/endriu2795/presentio-transcript-releases/releases)** e non compaiono nell’elenco dei file della repository qui sopra.

Installa una prima volta il pacchetto adatto al tuo computer. Le versioni successive vengono segnalate da Presentio; puoi anche usare **Impostazioni → Generali → Aggiornamenti → Verifica aggiornamenti**.

Le app non hanno ancora certificati commerciali Windows o Apple: il sistema può richiedere l’autorizzazione all’apertura.

Il codice sorgente è mantenuto in una repository privata.
